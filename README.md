# Servlet Tasks

This repository contains multiple Java Servlet practice tasks that demonstrate handling HTTP requests and responses in web applications. The tasks focus on form handling, user input processing, and basic product information management using Java Servlets.

## Technologies Used
- Java
- Servlets
- HTML
- Apache Tomcat Server
- HTTP Request & Response

## Tasks Included

### 1. Login Page and Login Response
A simple login page where the user enters credentials. The servlet processes the request and displays a login response message.

### 2. Login Information Message
This task captures login information from the user and displays a message confirming the login details.

### 3. Feedback Form and Feedback Response
A feedback form where users can submit their feedback. The servlet processes the input and returns a response message displaying the submitted feedback.

### 4. Product Information and Product Insertion
This task allows users to enter product details such as product name and price. The servlet processes the data and confirms successful product insertion.

### 5. Product Information and Product Retrieval
This module demonstrates retrieving and displaying product information using servlet request handling.

## Purpose of the Repository
The main purpose of this repository is to practice and understand how Java Servlets handle:
- Form submission
- User input processing
- Request and response handling
- Basic web application backend logic
